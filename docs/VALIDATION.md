## Limits

The dashboard is read-only and does not prove transaction inclusion, historical uptime, observer independence, or consumer safety. It has no private observer-service telemetry. Events are bounded to 10,000 blocks and 40 displayed logs. Latest-block reads may reorganize; L1 and L2 are separate observations. Freshness depends on the browser clock. The cache is per-process. No chain transactions, protocol configuration changes, formal proofs, production deployment, push, or PR merge were performed.
